# Simulated Cybersecurity lab: Detecting automated Internal API abuse.

When checking logs in security, network, or application settings it's important to set up a baseline to avoid false positives, undetected IP addresses, and variations in authentication.

##Setting up a baseline answers questions like:

What IPs, users, processes, and ports normally appear?

What does normal traffic volume look like (per minute/hour/day)?

What are expected authentication patterns?

Which errors or warnings occur regularly and are benign?
